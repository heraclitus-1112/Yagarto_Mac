# YAGARTO 小端32位内存表格设计

日期：2026-09-15

## 目标

把原生 App 的内存页改成用户提供的 YAGARTO/Insight 风格：默认从 `0x00008000` 开始，每行显示 16 字节，并按偏移 `0`、`4`、`8`、`C` 解释为四个小端32位字，右侧显示对应 ASCII。

## 端序规则

内存中的原始字节仍按地址递增保存，不改写调试器返回的数据。例如：

```text
地址递增的四个字节：FC FD EE FF
小端32位解释结果：  0xFFEEFDFC
```

因此表格显示 `0xFFEEFDFC` 才是截图中“Target is LITTLE endian”的含义。若直接把原始字节拼成 `0xFCFDEEFF`，那只是字节转录，不是该地址处的小端32位数值。

## 界面与交互

- 顶部只保留地址输入，初始值固定为 `0x00008000`，右侧显示 `Target is LITTLE endian`。
- 移除长度输入和“读取”按钮；窗口固定观察从当前地址开始的 112 字节，即 7 行。
- 地址步进以 `0x10` 为单位；手动输入合法十六进制地址后按回车，在暂停状态立即读取，在运行或未启动状态只更新待观察地址。
- 表头与7个地址行始终显示，即使尚未启动调试或读取失败；无数据单元格保持为空。
- 每次调试器进入暂停状态时自动刷新当前地址开始的112字节，包括首次启动调试、单步、断点停机和手动暂停。
- 表格列固定为“Address”、`0`、`4`、`8`、`C`、“ASCII”。四个数值列各显示一个 `0x` 加8位大写十六进制的32位字。
- 行地址使用 `0x` 加8位大写十六进制；ASCII 列显示16个原始字节，`0x20...0x7E` 显示字符，其余显示 `.`。
- 使用原生 `NSTableView` 的等宽、可选择文本、水平与垂直滚动；键盘与 VoiceOver 保留系统表格、行和单元格语义。

课程示例的首行应为：

```text
Address       0           4           8           C           ASCII
0x00008000    0xFFEEFDFC  0x00000001  0x00000002  0x00000003  ................
```

## 结构与数据流

- `YagartoCore` 继续读取原始字节；新增固定默认请求 `address: "0x8000"`、`byteCount: 112`，替换调试控制器原来的默认 `$sp`/64字节窗口。
- 调试器每次生成停止快照时已经按当前 `DebugMemoryRequest` 读取内存；`AppViewModel` 在接收快照时同步采用 `snapshot.memory`，使表格自动刷新。
- 用户在暂停状态提交新地址时，App 复用现有 `readMemory` 服务立即读取112字节；该请求同时成为之后各次停止快照的观察窗口。
- 展示层保留当前严格的 MI 十六进制校验和地址冲突检查，在此基础上把每4个连续原始字节按 little-endian 组合成 `UInt32`。
- 表格展示模型始终生成7行骨架；真实数据覆盖对应单元格。少于4字节的尾部不能伪装成完整32位字，应保持空白并提供“数据不完整”的辅助说明。
- 本次不增加内存编辑、标签表达式、任意长度选择或大端切换。

## 错误和状态

- 非法地址沿用现有中文地址校验提示；地址计算或112字节范围溢出时拒绝提交。
- 未启动或正在运行时，表格显示当前地址对应的7个空行，不发起额外读取。
- 自动读取失败时保留7行表格骨架，错误进入现有调试诊断区域，不用旧数据冒充本次结果。
- 切换工程、停止调试或切换 profile 后清除真实内存数据，但观察地址重置为 `0x00008000`。

## 测试

- 格式化器测试覆盖 `FC FD EE FF -> 0xFFEEFDFC`、四字一行、7行骨架、ASCII、非对齐地址、短尾部和损坏输入。
- `AppViewModel` 测试覆盖停止快照自动更新内存、运行期间不读取、提交地址后后续快照继续使用该窗口，以及停止/切换时清空数据。
- 原生表格测试覆盖6列标题、7行、word文本、空单元格、等宽可选择文本、滚动与真实系统辅助功能代理。
- 工作台宿主测试或可测试模型确认默认地址为 `0x00008000`，不再出现长度输入和“读取”按钮，并显示小端提示。
- 完整 Swift 测试和 Release App 构建必须通过；使用 `/Users/macbookair/ARM7/test-2` 实机冒烟检查首行4个word和ASCII。

## 验收标准

- 打开内存页时立即看到 Address、`0/4/8/C`、ASCII 和从 `0x00008000` 开始的7行表格。
- 首次调试停在 `start` 后无需点击按钮即可出现内存数据；以后每次单步或暂停都会刷新。
- 课程数据首行依次显示 `0xFFEEFDFC`、`0x00000001`、`0x00000002`、`0x00000003`。
- 地址输入改变后，行地址同步改变；处于暂停状态时自动读取，其他状态在下一次暂停时读取。
